# NTE-auto-ggg

即刻落槌自动竞拍脚本：自动开始匹配 → 逐回合读取估价并出价 → 识别结算跳过 → 出售 → 补道具 → 循环下一局。

纯 Python 实现（截屏 + RapidOCR + SendInput 模拟点击），无需安装游戏插件。

## 环境要求

- Windows，物理分辨率 **2560×1600**、系统缩放 100%、游戏**全屏**（所有坐标均为该分辨率下的物理像素，其他分辨率需自行校准）
- Python 3.13+（开发环境为 3.13.5）
- 依赖：`pip install -r requirements.txt`（rapidocr / mss / numpy / opencv-python / PyQt5）

## 运行

**必须以管理员身份运行**：游戏带 ACE 反作弊并以管理员运行，普通权限下脚本的鼠标/键盘注入会被 UIPI 静默拦截（脚本看似正常跑但游戏毫无反应）。

### 方式一：直接运行打包好的 exe（推荐）

双击 `dist/异环自动竞拍/异环自动竞拍.exe`，弹出 UAC 确认后即可使用，不需要安装 Python 环境。

- 首次运行会在 exe 同目录自动生成 `config.json`（可从内置副本释放），按需修改后重启生效
- 统计写到 `stats.json`，日志写到 `logs/YYYY-MM-DD.log`，都在 exe 同目录
- 整个目录要一起复制（`_internal` 不能少），可以打包成 zip 分发

### 方式二：源码运行

推荐直接双击 `run_as_admin.bat`（弹出 UAC 确认后启动）；或右键管理员运行你的 IDE/终端后再执行：

```
python main.py
```

默认打开 **1920×1080 挂机任务窗口**。即使不加管理员，程序启动时也会自动请求提权（UAC 弹窗 → 确认后以管理员身份重启界面）。

> 窗口尺寸按**物理像素**计算：界面按 1440×810 逻辑像素排版，`QT_SCALE_FACTOR` 钉为 4/3（见 `app.py` 顶部与 `ui.create_app()`），所以屏幕上就是真实的 1920×1080，字体与控件同比例放大，也不会被系统 150%/200% 缩放再放大一次。

### 打包

```bash
pip install pyinstaller
pyinstaller build.spec --noconfirm --clean
```

产物在 `dist/异环自动竞拍/`（onedir 模式，约 580MB，主要是 onnxruntime 与 MKL）。若启动异常需要看报错，可构建带控制台的调试版：

```bash
BUILD_CONSOLE=1 pyinstaller build.spec --noconfirm --clean
```

打包后可跑一次自检，确认 numpy / opencv / onnxruntime / OCR 模型都完好：

```bash
dist/异环自动竞拍/异环自动竞拍.exe --selftest
```

> 注意：本机是 conda 环境，PyQt5 的 pyd 依赖 `Qt5Core_conda.dll` 这类带 `_conda` 后缀的名字，PyInstaller 默认 hook 解析不到，`build.spec` 里已显式收集整条 Qt/PIL 依赖链，并精简了 MKL（只留调度层与常用内核），否则体积会多出约 380MB。

### 界面说明

| 区域 | 内容 |
|---|---|
| 挂机任务页 | 任务卡：标题与运行状态胶囊、第 N 局/回合/计时、采集日期、今日局数/回合/出价/采集次数（竖向排列）、模式选择（普通 / 巨物 / 至尊）、右下角「开始任务 / 停止任务」 |
| 参数配置页 | 采集间隔、游戏分辨率、窗口标题、空跑/步进模式、出价倍率与加价区间、出售红键阈值、各场景等待秒数，改完点「保存配置」写回 `config.json` |
| 右侧运行日志 | 按 tag 着色（估价灰 / 出价绿 / 高价橙 / 结算蓝 / 空跑紫），带搜索、清空、复制、导出为 txt，右上角可折叠成窄条；日志按天落盘，重开自动接着上次 |

模式选择目前提供三种，默认「普通模式」。**三种模式目前仅展示文案，只有普通模式的流程是已实现的，另两种待后续设计**：

| 模式 | 状态 | 说明 |
|---|---|---|
| 普通模式 | 可用（默认） | 角色搭配黑羽或小吱，第一回合使用超级鉴定仪器随机展示 6 件藏品。 |
| 巨物模式 | 暂未开放 | 角色搭配黑羽或小吱，第一回合使用超级鉴定仪器展示 6 件藏品，第二回合使用特殊鉴定仪器展示轮廓最大的一件藏品。 |
| 至尊模式 | 暂未开放 | 角色搭配黑羽或小吱，第一回合使用超级鉴定仪器展示 6 件藏品，第二回合使用九格均价仪器显示九格藏品的平均价值，第三回合使用至尊鉴定仪器展示信息完全未知且品质最高的一件藏品。 |

点击未开放的模式会在底部提示「暂未开放」，不会切换。选中状态记在 `TaskCard.mode`，暂不落盘。

运行中随时可点「停止任务」；步进模式下会出现「下一步」按钮，每次点击前等待放行。统计数字持久化在 `stats.json`，跨日自动清零。

界面刻意保持轻量（无自绘动画、无进度条）：窗口计时器只在任务运行时每秒走一次，空闲时完全停掉，配合游戏内的最低画质设置进一步降低整体功耗。

### 日志持久化

运行日志按天写入 `logs/YYYY-MM-DD.log`（`时间<TAB>正文`），启动时自动回填最近 2000 条，所以关掉再打开能直接接着看上次的记录。超过 30 天的日志文件会自动清理；点界面上的「清空」会同时清掉当天的日志文件，避免重启后又冒出来。

## 工作流程

```
启动等待10s → 点开始匹配（首局不购买道具）
  → 第1回合使用超级鉴定仪器，OCR 读估价 → 出价
  → 第3/5回合读估价 → 出价（>500万切换889万高价公式）；第2/4回合直接出价
  → 识别到「跳过」→ 等3s → OCR 读最终估价
      · 最终估价 > 180万：不点红色按键，直接点两下出售
      · 最终估价 ≤ 180万：先点红色按键，再点两下出售（第二下关闭「获得xxx金币」弹窗）
  → 点退出 → 等冷却 → 第2局起先购买道具 → 下一局循环
```

其它游戏内弹窗处理：

- 出价 > 200万时点「本次出价过高是否继续」的**继续**
- 开始匹配超时 120s 自动重试 3 次，仍失败则致命退出

## 功能介绍

本项目的主要功能是解放双手全自动拍卖，可自动出售低价值藏品，防止仓库已满，默认使用小吱，并自动使用扫6件和补道具，适合那些永恒之心已经毕业，但是又想拿大红的玩家，建议金贝铢 > 2500万使用。
当前版本游戏中的大红一共有六件：

| 名称 | 价值 | 类别 |
|---|---|---|
| 超级存储盘 | 5,121,024 | 科技类 |
| 翠刃 | 8,989,898 | 宝石类 |
| 碧波天垂 | 11,235,813 | 古董类 |
| 夜光杯 | 16,800,000 | 食品类 |
| Pendragon模型 | 20,171,210 | 日用类 |
| 金锦鲤雕像 | 22,668,888 | 异象类 |

所有大红价格均大于 500 万，故选择 500 万作为分界。若未能秒杀大红，则会疯狂加价，亏本拿大红。

> **500 万高价阈值与 200 万二次确认阈值均为固定常量**（定义在 `bid.py` 的 `HIGH_THRESHOLD` / `CONFIRM_POPUP_THRESHOLD`），不在界面暴露、也不从 `config.json` 读取：前者由大红最低价 512 万决定，后者是游戏内弹窗自带的固定行为，改动没有意义。

## 出价公式（config.bid）

| 场景 | 公式 |
|---|---|
| 本局估价 ≤ 500万 | `估价 × 1.3 + 本局累计随机加价`，每轮随机加 `randint(bonus_wan_min, bonus_wan_max)` 万（默认 1~5 万） |
| 本局任一回合估价 > 500万（记 high_i，本局永久生效） | `8.89M + 3.35M × (回合数 − high_i)` |

结果向上取整到万，换算成数字序列（如 1540000 → `154`）后用数字键 + 万键输入。估价缺失时该回合不出价；`bid.fake_estimate` > 0 可用于空跑验证公式。

## 配置（config.json）

唯一需要按需修改的文件。关键字段：

| 字段 | 说明 |
|---|---|
| `screen` | 物理分辨率，需与游戏一致 |
| `mouse.move_duration` | 鼠标移动耗时，`0` 为瞬移 |
| `loop.*` | 各场景等待秒数：`startup_wait` 启动、`round_wait` 每回合、`cooldown_wait` 退出后到下一局、`sell_wait` 两下出售之间、`settle_wait` 跳过后等结算等 |
| `regions` | 3 个 OCR 识别框（回合/估价/跳过动画），矩形 `[[左上],[右下]]` |
| `actions` | 各按钮的点击中心点 `[x,y]`，组内 `{"wait": 秒}` 为点后等待；`数字0~9`/`数字万` 为出价小键盘 |
| `bid` | 出价公式参数（见上表）；`high_threshold` / `confirm_popup_threshold` 已固化为代码常量，不再从配置读取 |
| `debug.dry_run` | 只识别不点击、跳过等待（界面上「空跑」开关亦可切换） |
| `debug.step` | 每个点击前等待放行，验证点击顺序（界面上「步进」开关亦可切换） |

**坐标语义**：`actions` 中的坐标只点击不识别；`regions` 中的矩形文本框做 OCR 读取。全部点击点清单见 `coordinates.txt`。

## 文件结构

```
main.py        入口：启动图形界面
app.py         界面启动器（DPI 感知、自提权、装配 worker 与窗口）
ui.py          1920×1080 主窗口：任务卡、模式选择、开始/停止
log_panel.py   右侧运行日志面板（着色 / 搜索 / 复制 / 导出 / 折叠）
settings_page.py 参数配置页（写回 config.json）
widgets.py     通用控件（Row / StatTile / Chip / DateField / NumberField 等）
theme.py       配色、QSS 主题、SVG 线性图标
bus.py         界面 ↔ 工作线程通信（ConfigHolder / Control / Signals）
worker.py      BotWorker 线程：跑主循环，转发日志/状态/统计
stats.py       局数/回合/出价统计与持久化（stats.json）
log_store.py   运行日志按天落盘与回填（logs/YYYY-MM-DD.log）
scenes.py      状态机：启动/等待进入竞拍/回合动作/结算/冷却
state.py       全局状态（阶段、回合、估价、high_i、累计加价）
bid.py         出价公式与万位取整
actions.py     动作执行（点击/等待/按键、dry_run、步进、提权兜底）
mouse.py       SendInput 鼠标曲线移动 + 点击
ocr.py         RapidOCR 封装（放大预处理、日志静默）
screen.py      mss 截屏
window.py      窗口激活 + 管理员权限自检（UIPI 守卫）
config.json    全部可调配置
run_as_admin.bat 管理员启动器（源码模式）
build.spec     PyInstaller 打包配置
app.ico        程序图标
```
